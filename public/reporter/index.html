Reusable Writeup

RedSecReporter is the pentest reporting and findings management tool for RedSecTools. It provides a structured workflow for creating penetration test reports, managing security findings, and generating professional deliverables.

Projects are built on customisable report designs that define the section layout, finding fields, and output format. Each project supports team collaboration with role-based access for leads, pentesters, and reviewers. Findings are tracked through a full lifecycle from draft to approval with severity classification and optional CVSS scoring.

A shared finding template library lets teams reuse and standardise common vulnerability descriptions. Report sections support rich text editing for executive summaries, scope definitions, methodology descriptions, and custom content.

Pentest Reports Findings Management CVSS Scoring PDF Generation Team Collaboration Template Library Report Designs

Projects

Create pentest projects from report designs. Assign team members with defined roles, set due dates, and track project status through draft, review, approval, and delivery stages. Duplicate completed projects to reuse structure for similar engagements.

Findings

Document security findings with structured fields including description, attack scenario, remediation guidance, and references. Each finding is classified by severity with optional CVSS vector scoring. Findings flow through a review pipeline from draft to approved, supporting retest tracking and client-ready status.

Report Designs

Define report templates with custom section layouts, finding field schemas, and output formatting. Designs control which fields are available, how findings are ordered and grouped, and the overall report structure. Multiple designs support different engagement types such as external, internal, web application, and red team assessments.

Finding Templates

Build a shared library of common findings with pre-written descriptions, severity defaults, and remediation guidance. Templates speed up finding creation and ensure consistency across engagements and team members.

Sections

Create structured report sections for executive summaries, scope definitions, methodology descriptions, and custom content. Sections are ordered independently and can be included or excluded from the final report.
