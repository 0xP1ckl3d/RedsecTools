What is RedSecShare?

RedSecShare is an encrypted file sharing tool built by RedSec Offensive Security. Files are encrypted in your browser before upload — the server only stores unreadable ciphertext and never has access to your files or encryption keys.

How Encryption Works

Link-Only Encryption (default)

Your browser generates a random 256-bit AES key and encrypts the file content and filename locally using AES-256-GCM. The key is never sent to the server.

The share link contains the key in the URL fragment (after #). URL fragments are never transmitted to the server.

https://example.com/s/share_id#encryption_key

The server only sees the share ID. The key after # stays in the browser.

Password-Protected Files (double encryption)

Adding a password applies a second layer of encryption:

  1. Your file is encrypted with a random key K (stored in the URL fragment)
  2. The resulting ciphertext is re-encrypted with a key derived from your password using PBKDF2 with 600,000 iterations
  3. Only the doubly-encrypted ciphertext is uploaded

The recipient needs both the link and the password to decrypt the file.

Security Features

  • Zero-knowledge server — files and filenames are encrypted before upload.
  • Encrypted filenames — even file names are encrypted.
  • Burn after reading — files can self-destruct after first download.
  • Auto-expiry — all files automatically expire and are permanently deleted.
  • Admin-configured limits — client-side encryption with server-enforced size ceilings.
  • No tracking — no cookies, no analytics, no accounts.
