RedSecShare

What is RedSecShare?

RedSecShare is an encrypted file sharing tool built by RedSec Offensive Security. It lets you share files through end-to-end encrypted links using server-configurable upload limits. Files are encrypted in your browser before upload — the server only stores unreadable ciphertext and never has access to your files or encryption keys.

How Encryption Works

Link-Only Encryption (default)

When you upload a file without a password, your browser generates a random 256-bit AES key and encrypts the file content and filename locally using AES-256-GCM. The key is never sent to the server.

The share link contains the key in the URL fragment (after #). URL fragments are never transmitted to the server, so the server only ever stores unreadable ciphertext. When the recipient opens the link, their browser downloads the encrypted file, extracts the key, and decrypts it locally.

https://example.com/s/ share_id#encryption_key

The server only sees the share ID. The key after # stays in the browser.

Password-Protected Files (double encryption)

Adding a password applies a second layer of encryption:

  1. Your file is encrypted with a random key K (stored in the URL fragment)
  2. The resulting ciphertext is then re-encrypted with a key derived from your password using PBKDF2 with 600,000 iterations and SHA-256
  3. Only the doubly-encrypted ciphertext is uploaded to the server

The recipient needs both the link and the password to decrypt the file.

Security Features

  • Zero-knowledge server — files and filenames are encrypted before upload. The server never sees plaintext content, filenames, or encryption keys.
  • Encrypted filenames — even file names are encrypted. The server only stores an opaque identifier.
  • Burn after reading — files can self-destruct immediately after the first download. The encrypted file is deleted from disk.
  • Auto-expiry — all files automatically expire and are permanently deleted from disk and database.
  • Admin-configured limits — share files with client-side encryption and streaming upload while the server enforces the configured file-size and file-count ceilings.
  • No tracking — no cookies, no analytics, no accounts. File shares are completely anonymous.
