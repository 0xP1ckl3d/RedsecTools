RedSecVault

Zero-knowledge credential manager

RedSecVault is an encrypted credential and secure notes manager built into RedSecTools. All encryption and decryption happens entirely in your browser — the server never sees your passwords, API keys, or notes.

How it works

  • Personal vaults are encrypted with a key derived from your login password using PBKDF2 (600,000 iterations). The vault unlocks automatically when you sign in.
  • Team vaults use a shared AES-256-GCM master key, distributed to each member via RSA-OAEP encryption — the same key exchange pattern used by RedSecTeam chat.
  • Entry sharing lets you share individual entries with other users, even across different vaults, using RSA key wrapping.

Entry types

  • Password — username, password, URL
  • Secure Note — freeform encrypted text
  • API Key — key, service name
  • SSH Key — private key, public key, passphrase
  • TOTP — time-based one-time password secrets with live code generation
  • Custom — user-defined fields

Security properties

  • AES-256-GCM encryption via Web Crypto API
  • PBKDF2 key derivation with 600K iterations (personal vaults)
  • RSA-OAEP 2048-bit key wrapping (team vaults, entry sharing)
  • Server stores only opaque ciphertext — zero server-side crypto
  • Built-in TOTP code generation using HMAC-SHA1/SHA256/SHA512
  • Password generator with configurable length and character sets
  • Vault audit log for access tracking
  • Entry version history
