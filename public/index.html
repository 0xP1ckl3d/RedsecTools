About RedSecTools

RedSecTools is a self-hosted security operations workspace for small offensive security teams. It brings secure sharing, team knowledge, scheduling, reporting, threat monitoring, surveys, bulletins, and scoped AI assistance into one permission-aware dashboard.

Security Model

RedSecTools is designed so plaintext content is encrypted in the browser before being submitted to the server. During normal operation, the server stores opaque ciphertext and does not receive paste, file, chat, or vault plaintext. This does not protect against a malicious or compromised server that serves modified JavaScript to clients.

Access Control

Tool visibility follows your role permissions, and sensitive actions are enforced by server-side API checks. If a tool is missing from your dashboard, ask an administrator to review your role or tool access.

What Is Available

Secure Sharing

RedSecPaste, RedSecShare, RedSecTeam, and RedSecVault support encrypted text, files, messages, credentials, API keys, SSH keys, TOTP codes, and secure notes.

Team Operations

BulletinBoard, RedSecCal, shortcuts, and the homepage help coordinate notices, project allocations, reminders, team links, and day-to-day activity.

Knowledge & Delivery

RedSecWiki, RedSecSurvey, and RedSecReporter cover Markdown knowledge bases, public or internal surveys, findings, evidence, CVSS data, and report generation.

Monitoring & Assistance

RedSecThreat monitors feeds and extracts indicators, while RedSecAI can help with scoped, permission-aware workflows when enabled by an administrator.

Basic Use

  1. Open the Tools view to access the tools available to your account.
  2. Star up to five favourite tools and five favourite shortcuts for Quick Access on the homepage.
  3. Use Shortcuts for personal links and administrator-managed team links.
  4. Check Bulletin Board for current notices, scheduled messages, and pinned updates.
  5. Use each tool's embedded About view when you need tool-specific guidance.

Good Habits

  • Share paste and file links carefully, because URL fragments and passwords are required to decrypt protected content.
  • Keep MFA enabled and report unexpected access, missing tools, or permission problems to an administrator.
  • For RedSecAI, keep requests focused and review confirmation cards before approving any write action.
  • Use team-wide tools for operational data and encrypted tools for secrets or sensitive collaboration.
