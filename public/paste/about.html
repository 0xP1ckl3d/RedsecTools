RedSecPaste

What is RedSecPaste?

RedSecPaste is a privacy-first encrypted pastebin built by RedSec Offensive Security. It lets you share text, code snippets, and sensitive notes through end-to-end encrypted links that even the server cannot read. No accounts, no tracking, no plaintext ever touches our infrastructure.

How Encryption Works

Link-Only Encryption (default)

When you create a note without a password, your browser generates a random 256-bit AES key and encrypts your note locally using AES-256-GCM — a modern authenticated encryption algorithm. The key is never sent to the server.

The resulting share link contains the key in the URL fragment (after the #). URL fragments are never transmitted to the server by browsers, so the server only ever stores unreadable ciphertext. When the recipient opens the link, their browser extracts the key from the fragment and decrypts the note locally.

https://example.com/p/ paste_id#encryption_key

The server only sees the paste ID. The key after # stays in the browser.

Password-Protected Notes (double encryption)

Adding a password applies a second layer of encryption on top of the link-based encryption:

  1. Your note is encrypted with a random key K (stored in the URL fragment)
  2. The resulting ciphertext is then re-encrypted with a key derived from your password using PBKDF2 with 600,000 iterations and SHA-256
  3. Only the doubly-encrypted ciphertext is sent to the server

To decrypt, the recipient needs both the link (containing key K) and the password. Neither alone is sufficient — this is true two-factor encryption.

Security Features

  • Zero-knowledge server — the server never has access to your plaintext or encryption keys. All cryptographic operations happen in your browser using the native Web Crypto API.
  • Burn after reading — notes can be set to self-destruct immediately after the first viewing. The server atomically deletes the ciphertext the moment it's retrieved.
  • Auto-expiry — all notes automatically expire and are permanently deleted. Choose from 1 hour, 12 hours, 24 hours, or 3 days.
  • Strict CSP & security headers — HTTP Strict Transport Security, Content Security Policy, no-referrer policy, and frame blocking all enforced at the server level.
  • No tracking — no cookies, no analytics, no accounts. Notes are completely anonymous.
  • Syntax highlighting — optional highlighting for 30+ programming and markup languages, applied client-side after decryption.

How to Use

  1. 1

    Write or paste your note

    Type or paste the content you want to share. Optionally select a syntax highlighting language.

  2. 2

    Set your options

    Add an optional password for two-factor encryption. Enable "Burn after reading" for one-time notes. Choose an expiry time (1h to 3 days).

  3. 3

    Share the link

    Copy the generated link and send it to your recipient. The encryption key is embedded in the link — keep it safe.

  4. 4

    Recipient opens the link

    Their browser automatically extracts the key and decrypts the note. If password-protected, they'll be prompted to enter it. Nothing is sent to the server during decryption.
