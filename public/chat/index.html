RedSecTeam

End-to-end encrypted team chat

RedSecTeam is an end-to-end encrypted messaging platform built into RedSecTools. All messages are encrypted in your browser before being sent — the server never sees your conversations.

How it works

  • Hybrid encryption — each user has an RSA-2048 key pair. Conversation keys are AES-256-GCM, distributed to members via RSA-OAEP encryption.
  • Key epochs — when members join or leave, a new conversation key is generated. Forward secrecy for group membership changes.
  • Private key backup — your RSA private key is encrypted with your login password (PBKDF2, 600K iterations) and stored on the server as an opaque backup.
  • Direct and group chats — private 1-on-1 conversations and group channels with member management.
  • Embeds — share RedSecPaste links, RedSecShare files, and RedSecVault entries directly in conversations as encrypted embed cards.

Security properties

  • RSA-OAEP 2048-bit + AES-256-GCM hybrid encryption
  • PBKDF2 key derivation with 600K iterations (private key backup)
  • Server stores only encrypted ciphertext — zero server-side crypto
  • Messages auto-expire after 7 days
  • Real-time WebSocket delivery with reconnect
  • Presence indicators and typing notifications
